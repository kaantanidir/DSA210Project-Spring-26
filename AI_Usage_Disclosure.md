# AI Usage Disclosure

This project was completed by the student. AI tools were used as support tools for documentation revision, coding support, debugging assistance, and repository organization.

## How AI was used in this project

AI assistance was used for the following support tasks:

1. **Documentation revision**
   - improving the wording, grammar, and organization of the README file,
   - aligning the README and report structure with the course project guidelines,
   - improving the explanation of findings, limitations, and future work.

2. **Repository organization**
   - identifying which files should remain in the final GitHub repository,
   - helping distinguish active pipeline scripts from outdated or optional scripts,
   - suggesting a cleaner reproducible project structure.

3. **Debugging and command-line support**
   - helping interpret Python error messages,
   - helping debug missing dependency and missing file errors,
   - explaining Git commands such as `git status`, `git add`, `git commit`, and `git push`.

4. **Pipeline and analysis revision support**
   - suggesting that GDELT should not remain in the final pipeline because of API rate-limit and reproducibility problems,
   - suggesting the Alternative.me Crypto Fear & Greed Index as a more stable sentiment-based enrichment source,
   - helping revise the analysis pipeline to include market, attention, and sentiment features.

5. **Writing and presentation support**
   - improving written explanations of statistical tests, figures, machine learning outputs, and project limitations.

## What AI did not do

AI did not independently collect the final datasets. The final processed datasets, statistical test outputs, figures, and machine learning results were generated locally by running the project scripts on the student's computer.

AI did not replace the student's project decisions, execution, review, or final responsibility. The student reviewed, executed, and approved the code, outputs, and final repository content before submission.

## Specific outputs generated locally

The following categories of final output were generated by running the project scripts locally:

- processed datasets under `data/processed/`,
- cleaned Fear & Greed output under `data/outputs/fear_greed_index.csv`,
- hypothesis test results under `data/outputs/hypothesis_test_results.csv`,
- machine learning result tables under `data/outputs/ml_results_summary.csv`,
- generated figures under `data/outputs/`,
- analysis reports under `reports/`.

## Student responsibility

All project decisions, dataset selection, preprocessing choices, script execution, analysis steps, interpretation of findings, and final submission were reviewed and approved by the student. The student remains fully responsible for the content of the repository and the submitted work.
